WhatsApp is a first-party source. The other three assets are obtained from the SVGL brand-artwork mirror, **not directly from Google/Meta brand portals**. The established Gmail SVG was selected instead of an unverified recent gradient replacement. No SVG path was generated, traced, re-coloured, simplified or redrawn for this implementation. The source artwork and its rendered presentation were visually reviewed; proportions are preserved with `object-fit: contain`.

Vendoring an asset does not transfer trademark ownership or establish permission for endorsement. No network request to a provider or external logo CDN is made when the homepage renders.
